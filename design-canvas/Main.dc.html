Migration plan: nightly batch to streaming

Draft  ·  last edited 4 minutes ago by Bruno Salas

The nightly batch has been the reconciliation path since 2019, and every incident review since March has ended at the same sentence: the ledger is correct by morning and wrong all afternoon. Moving to a stream does not make the ledger more correct. It makes the window in which it is wrong short enough to matter.

What we are not changing

The schema stays. The reconciliation rules stay, character for character, because a migration that changes both the transport and the rules cannot be bisected when it goes wrong.Bruno Salas The only thing that moves is when a row is written.

We keep the batch running in parallel for two full quarters. It costs about forty euros a month in compute and it is the only way to answer the question an auditor will actually askAna Requena, which is whether the two paths ever disagreed.

Rollout

  1. Shadow writes, no reads. Four weeks.
  2. Reads behind a per-tenant flag, starting with internal tenants.Clara Mota
  3. Batch demoted to a nightly assertion rather than a source.
